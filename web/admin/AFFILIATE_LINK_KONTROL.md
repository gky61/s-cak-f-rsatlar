# Affiliate Link Kontrol - Kendi Linkiniz mi?

## 🔍 Link Analizi

Verdiğiniz link:
```
https://www.hepsiburada.com/kampanyalar/secili-giyilebilir-teknoloji-urunlerinde-500tl-kupon-firsati?ftid=fty6x2mj8pdbonx7&utm_source=linkgelir&utm_medium=referral&utm_campaign=urun_paylasim
```

## ✅ Bu Link Sizin mi?

### `utm_source=linkgelir` Ne Anlama Geliyor?

**`utm_source=linkgelir`** genellikle **Hepsiburada Link Gelir programının genel değeridir**. Bu, herkes için aynı olabilir veya sizin özel partner ID'niz olabilir.

### Nasıl Kontrol Edilir?

1. **Hepsiburada Link Gelir Paneline Giriş Yapın:**
   - https://www.hepsiburada.com/link-gelir
   - Hesabınıza giriş yapın

2. **Link Oluşturucu'yu Kullanın:**
   - Bir ürün paylaşın
   - Oluşan linkteki `utm_source` değerini kontrol edin
   - Eğer `utm_source=linkgelir` ise → Bu genel değerdir, sizin linkinizdir ✅
   - Eğer farklı bir değer varsa (örn: `utm_source=partner123`) → O değeri kullanın

3. **Kazancınızı Kontrol Edin:**
   - Link Gelir panelinde "Kazançlarım" bölümüne gidin
   - Bu linkten yapılan alışverişlerde komisyon kazanıyorsanız → Bu sizin linkinizdir ✅

## 🔧 Özel Partner ID'niz Varsa

Eğer Hepsiburada Link Gelir programında **özel bir partner ID**'niz varsa:

1. **Link Gelir panelinden ID'nizi bulun**
2. **`config.js` dosyasını güncelleyin:**

```javascript
hepsiburada: {
    utmSource: 'SİZİN_ÖZEL_ID', // Özel partner ID'niz
}
```

3. **Sistem otomatik olarak bu ID'yi kullanacak**

## 📝 Örnek Senaryolar

### Senaryo 1: Genel Link Gelir ID
```
utm_source=linkgelir
```
- ✅ Bu genel değerdir, herkes için aynıdır
- ✅ Sizin linkinizdir (Link Gelir programına üyeyseniz)
- ✅ Komisyon kazanırsınız

### Senaryo 2: Özel Partner ID
```
utm_source=partner123
```
- ✅ Bu özel partner ID'nizdir
- ✅ Sadece sizin linkinizdir
- ✅ Komisyon kazanırsınız

## ⚠️ Önemli Notlar

1. **`utm_source=linkgelir` genellikle doğrudur:**
   - Hepsiburada Link Gelir programında genellikle bu değer kullanılır
   - Eğer Link Gelir programına üyeyseniz, bu sizin linkinizdir

2. **Kesin kontrol için:**
   - Link Gelir panelinden bir link oluşturun
   - Oluşan linkteki `utm_source` değerini kontrol edin
   - Eğer `linkgelir` ise → Doğru ✅

3. **Komisyon kontrolü:**
   - Link Gelir panelinde "Kazançlarım" bölümünden kontrol edin
   - Bu linkten yapılan alışverişlerde komisyon görüyorsanız → Bu sizin linkinizdir ✅

## 🎯 Sonuç

**Verdiğiniz link muhtemelen sizin linkinizdir** çünkü:
- ✅ `utm_source=linkgelir` Hepsiburada Link Gelir programının standart değeridir
- ✅ Sistem tarafından doğru şekilde oluşturulmuştur
- ✅ Link Gelir programına üyeyseniz, bu linkten komisyon kazanırsınız

**Kesin kontrol için:** Hepsiburada Link Gelir panelinden bir link oluşturup `utm_source` değerini karşılaştırın.
